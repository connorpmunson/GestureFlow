# GestureFlow
## Gesture cheat sheet

Use your right hand. Calibrate with your elbow resting. Disable Preview only, then change closed fist to open palm to turn control ON. Static poses never toggle.

| Do this | Make this gesture | Remember |
| --- | --- | --- |
| Move pointer | Only index finger extended | Move your fingertip within the calibrated area. |
| Turn ON | Closed fist, then open palm | Hold first 0.25 seconds, second 0.30 seconds. |
| Click | Thumb touches SIDE of straight index | Keep other fingers curled; release contact to complete click. |
| Drag / select | Hold thumb against index side | Move index fingertip; release contact to drop. |
| Talk to FlowSpeak | Middle bent to thumb; index, ring, pinky extended | Hold the whole shape to speak; release/change shape to finish. |
| Enter / send | Ring bent to thumb; index, middle, pinky extended | Hold 0.18 seconds for one Enter; release/change shape to repeat. |
| Scroll | Thumbs-up; all four fingers curled | Hold 0.16 seconds; move up/down. Point with index to return. |
| Right-click | Thumb + pinky out; other three folded | Hold shaka for about 0.30 seconds. Leave pose to rearm. |
| Switch window | Index + pinky out; middle, ring, thumb closed | Hold to cycle every 0.75 seconds; release to select highlighted window. |
| Turn OFF | Open palm, then closed fist | Same timing; camera stays on, commands stop. |

## Immediate control

- Ctrl+Alt+G: toggle the gesture-control lock from anywhere.
- Escape: lock controls when GestureFlow is focused.
- Power sequence: finish within 1.5 seconds. Relax/change pose before a NEW sequence; simply reopening the OFF-ending fist will not activate.
- Hand loss releases held input and freezes movement, but keeps control ON. Pointing does not turn the system ON/OFF.

## Three habits that help

1. Calibrate neutral, left, right, up, down: hold each for three seconds with your elbow resting. Adjust horizontal/vertical sensitivity separately.
2. Click on the index SIDE. For FlowSpeak/Enter, keep the other three fingers extended. Gestures never bypass a keyboard lock.
3. Wait for dictated text before Enter; it follows the focused app. Release physical modifiers before Enter or window switching.

FlowSpeak must be running with its Right Control shortcut. GestureFlow leaves it unchanged. Hand loss or turning control OFF releases a hold and can finish recording; it does not cancel it.
